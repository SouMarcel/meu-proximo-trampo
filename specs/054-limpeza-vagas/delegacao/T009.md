Tamanho: minor

## Contexto

Projeto: a página React de uma ferramenta local de busca de emprego. Você está na branch `frontend-react`. O servidor
ganhou a "limpeza de vagas antigas":

- uma vaga pode vir **arquivada**, com o campo `arquivada_em` (texto ISO) e sem descrição nem análise;
- há um resultado novo, `"sem_resposta"`;
- há quatro rotas novas, descritas abaixo.

Esta tarefa prepara os tipos e o serviço, e esconde as vagas arquivadas das listas e dos contadores. A aba que usa
tudo isso é outra tarefa.

Arquivos de referência:

- `src/types/api.ts`: `Resultado` (perto da linha 66) e a interface `Vaga` (perto da linha 123).
- `src/utils/rotulos.ts`: `RESULTADOS: Record<Resultado, string>`.

```ts
/** Limpeza de vagas antigas (spec 054). */
export type GrupoLimpeza = "fora" | "pendente" | "dispensadas" | "sem_resposta"
export type ResultadoLimpeza = "nao_aprovado" | "desisti" | "cancelada" | "sem_resposta" | "sem_resultado"
export interface CriterioGrupo {
  ligado: boolean
  dias: number
}
export interface CriteriosLimpeza {
  fora: CriterioGrupo
  pendente: CriterioGrupo & { nota_abaixo_de: number | null }
  dispensadas: CriterioGrupo & { resultados: ResultadoLimpeza[] }
  sem_resposta: CriterioGrupo
}
export interface EstadoLimpeza {
  criterios: CriteriosLimpeza
  arquivadas: number
  tamanho_kb: number
}
export interface VagaNaPrevia {
  id: string
  titulo: string
  empresa: string
  plataforma: string
  dias: number
  destaques: string[]
}
export interface GrupoNaPrevia {
  acao: "arquivar" | "encerrar"
  ligado: boolean
  dias: number
  vagas: VagaNaPrevia[]
}
export interface PreviaLimpeza {
  grupos: Record<GrupoLimpeza, GrupoNaPrevia>
  total: number
  destacadas: number
  arquivadas: number
  tamanho_kb: number
}
export interface RespostaAplicarLimpeza {
  arquivadas: number
  encerradas: number
  ignoradas: string[]
  antes_kb: number
  depois_kb: number
  backup: string | null
}
```

   - acrescente `RESULTADOS_LIMPEZA: Record<ResultadoLimpeza, string>` = `{ nao_aprovado: "Não aprovado", desisti: "Desisti", cancelada: "Vaga cancelada", sem_resposta: "Sem resposta", sem_resultado: "Sem resultado escolhido" }`.
