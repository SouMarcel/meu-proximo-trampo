# T004 — Área Páginas com Completo ou "Até [N] páginas" e o limite obrigatório junto

Spec: 052-paginas-ate-n
Tamanho: minor

## Contexto

Projeto: a página React de uma ferramenta local de busca de emprego. Você está na branch `frontend-react`. O diálogo
"Gerar currículo" fica em `src/components/curriculo/Curriculos.tsx`, função `GerarCurriculo`. Ele recebe do servidor
um catálogo (`Catalogo`, em `src/services/api/curriculo.ts`):

- `tecnicas`: caixas de marcar `{nome, padrao, explicacao}`, hoje desenhadas todas na seção "Técnicas". Uma delas é
  `paginas_obrigatorio` ("Limite de páginas obrigatório").
- `escolhas`: grupos de rádio `{nome, padrao, opcoes: {valor: rótulo}}`, desenhados pelo laço genérico
  `Object.entries(c.escolhas).map(...)`. Uma delas é `paginas`. A partir de agora, `paginas.opcoes` traz
  `"0": "Completo (sem limite, tudo do perfil)"` (só no currículo base; no currículo de uma vaga o "0" não vem) e
  `"1"` a `"5"` com os rótulos "Até 1 página" … "Até 5 páginas". O padrão é 2.

O estado das escolhas fica em `escolha` (`Record<string, unknown>`); `gerar()` envia `{...escolha}` com `paginas`
convertido para número.

## O que fazer

1. Na seção "Técnicas", não desenhe a caixa `paginas_obrigatorio` (filtre essa chave).
2. No laço de `c.escolhas`, trate `paginas` à parte (as outras escolhas continuam no laço genérico, sem mudança). A
   seção de `paginas` mostra o título `es.nome` e:
   - se o catálogo tem a opção `"0"`: um rádio com o rótulo da opção "0" (Completo);
   - um rádio "Até" seguido de um `<select>` com as opções diferentes de "0", na ordem numérica, cujo texto é só o
     número (1 a 5), seguido da palavra "página" quando o número escolhido é 1 e "páginas" nos outros casos.
     Mudar o select marca esse rádio. Sem a opção "0" (vaga), mostre só "Até [select] páginas", sem rádio.
   - logo abaixo, a caixa `paginas_obrigatorio`, no mesmo formato visual das caixas de Técnicas (nome em negrito e a
     explicação do catálogo com a classe `DICA`). Ela fica `disabled` (e com `opacity-60`) quando Completo está
     marcado.
3. Guarde o último N escolhido num estado próprio (padrão: o `paginas` inicial se for de 1 a 5, senão 2). Ao voltar
   do Completo para "Até", `paginas` volta a esse N, e a marcação da caixa obrigatória é a que estava.
4. Em `gerar()`, se `paginas` for 0, envie `paginas_obrigatorio: false`.
5. Use os mesmos estilos (classes Tailwind) que o arquivo já usa para rádios, caixas e o `<select>` (se não houver
   um select no arquivo, use `rounded-lg border border-slate-200 dark:border-slate-700 bg-white dark:bg-slate-900
   px-2 py-1 text-xs`). Textos em português do Brasil.

Não mude a lista de currículos (`ItemCurriculo`, `SecaoCurriculos`), nem a análise de reprovação, nem a API.
