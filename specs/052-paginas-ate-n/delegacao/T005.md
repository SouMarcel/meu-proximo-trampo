# T005 — Lixeira para apagar um currículo gerado

Spec: 052-paginas-ate-n
Tamanho: minor

## Contexto

Projeto: a página React de uma ferramenta local de busca de emprego. Você está na branch `frontend-react`. A lista de
currículos gerados fica em `src/components/curriculo/Curriculos.tsx`: `SecaoCurriculos` carrega a lista com
`curriculoApi.lista(vagaId)` num `useEffect` que depende de `[vagaId, versao]`, e cada item é um `ItemCurriculo`, que
mostra os botões PDF e .docx (`LinkArquivo`, classe `BTN_MINI`) num `<span className="flex gap-1.5 ml-auto">`. As
chamadas à API ficam em `src/services/api/curriculo.ts`, com `pedir<T>(metodo, caminho, corpo?)` de `../api`; a função
`mensagemDeErro(e, padrao)` (de `../../services/api`) dá o texto de um erro. Ícones vêm de `lucide-react`.

O servidor tem a rota nova `DELETE /api/curriculo/<nome>`: responde 200 `{apagado: nome}`; 400, 404 ou 409 com
`{erro: "texto"}` (409 = arquivo aberto em outro programa).

## O que fazer

1. Em `src/services/api/curriculo.ts`, acrescente
   `export const apagar = (nome: string) => pedir<{ apagado: string }>("DELETE", `/api/curriculo/${encodeURIComponent(nome)}`)`,
   perto de `lista`.
2. Em `Curriculos.tsx`:
   - `ItemCurriculo` recebe também `onApagado: () => void`.
   - Depois dos botões PDF e .docx, dentro do mesmo `<span>`, um botão com o ícone `Trash2` (`w-3.5 h-3.5`), classe
     `BTN_MINI`, `title` e `aria-label` "Apagar este currículo". Ao clicar:
     `window.confirm("Apagar este currículo de vez? O PDF, o .docx e os dados dele somem da pasta.")`; cancelado, não
     faz nada. Confirmado: desabilita o botão, chama `curriculoApi.apagar(m.nome)`; deu certo, chama `onApagado()`;
     deu erro, mostra uma linha no item com `className="text-xs text-rose-700 dark:text-rose-300"` e o texto de
     `mensagemDeErro(e, "Não deu para apagar o currículo.")`, e reabilita o botão.
   - Em `SecaoCurriculos`, passe `onApagado` que recarrega a lista (por exemplo, tirando o item apagado do estado
     `lista` com `setLista((l) => (l || []).filter((x) => x.nome !== m.nome))`).
3. Não mude o diálogo `GerarCurriculo`, a análise de reprovação nem outros componentes.
