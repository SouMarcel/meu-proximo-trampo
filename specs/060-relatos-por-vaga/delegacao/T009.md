# T009 — Seus relatos como caixa de entrada: Incorporar, Desfazer e os incorporados minimizados

Spec: 060-relatos-por-vaga
Tamanho: minor

## Contexto

Projeto: a página React de uma ferramenta local de busca de emprego. Você está na branch `frontend-react`. O
componente `src/components/perfil/Relatos.tsx` lista os relatos da pessoa (`perfilApi.relatos()`), com marcar,
"Revisar e levar ao perfil" (chama `perfilApi.revisarPerfil("relatos", ids)`; com IA a resposta é o estado de uma
geração em segundo plano e o componente chama `comecou(j)` do `useGeracao`; sem IA vinha `{sem_ia, aviso}`),
"Levar ao perfil", "Corrigir" e "Apagar", e no fim desenha `<SecaoRevisaoPerfil origem="relatos" />`. O contexto
`useGeracao()` (`src/contexto/Geracao.tsx`) expõe `versao`, que aumenta quando uma geração termina (veja como
`SecaoRevisaoPerfil` em `src/components/perfil/RevisaoPerfil.tsx` recarrega com `versao`). A API fica em
`src/services/api/perfil.ts` (`revisarPerfil`, `obterRevisao`, `relatos`, `apagarRelato`, …).

Regra nova (spec 060): a aba é uma caixa de entrada. O servidor passa a:
- no `POST /api/perfil/revisao` com `origem: "relatos"`, **incorporar**: a IA analisa, o que não diverge entra direto
  no perfil e as divergências ficam para a aba Conflitos. Sem IA, responde 400 com a mensagem (não há mais `sem_ia`
  nessa origem);
- no `GET /api/perfil/revisao?origem=relatos`, devolver também `incorporacao`: `{anterior: string | null, relatos:
  string[], entrou: {tipo: string, secao: string | null, cargo: string | null, novo: string | null}[], em: string} |
  null`;
- `POST /api/perfil/revisao/desfazer` (corpo `{}`) → `{ok: true}` (409 com mensagem se o perfil mudou depois).

## O que fazer

1. `src/services/api/perfil.ts`: tipo `Incorporacao` e campo opcional `incorporacao?: Incorporacao | null` na resposta
   de `obterRevisao`; função `desfazerIncorporacao = () => pedir<{ ok: boolean }>("POST",
   "/api/perfil/revisao/desfazer", {})`.
2. `Relatos.tsx`:
   - separe `pendentes = lista.filter((r) => !r.no_perfil)` e `incorporados = lista.filter((r) => r.no_perfil)`;
   - título "Seus relatos (N)" com N = pendentes; o texto explicativo vira: "O que você contou na candidatura
     assistida e na análise de reprovação. Enquanto não entra no perfil, cada relato vale só na vaga em que foi
     escrito. Marque e clique em Incorporar: a IA põe no perfil o que encaixa e manda para Conflitos o que diverge.";
   - o botão principal vira "Incorporar ao perfil (N)" (mesma chamada `revisar(marcados)`); o botão por item "Levar ao
     perfil" vira "Incorporar"; "Apagar" dos pendentes vira "Excluir" (mesma ação);
   - se `revisarPerfil` voltar com erro (ex.: sem IA), mostre a mensagem com `onErro`, como hoje;
   - carregue `perfilApi.obterRevisao("relatos")` junto com os relatos e de novo quando `versao` mudar (e depois de
     desfazer); guarde `incorporacao` e quantas `discordancias` sem `escolha` a revisão tem (com `gravada_em` vazio);
   - quando houver `incorporacao` com `entrou` não vazio, um quadro verde-claro "Entrou no perfil:" com a lista
     (`novo`, e a seção/cargo em texto pequeno) e o botão "Desfazer" (confirmação "Desfazer a incorporação? O perfil
     volta à versão anterior e os relatos voltam para cá."), que chama `desfazerIncorporacao`, recarrega tudo e chama
     `onPerfilMudou`;
   - quando houver discordâncias abertas, a linha "N ponto(s) para decidir em Conflitos." com um botão "Abrir
     Conflitos" que chama uma prop nova opcional `onAbrirConflitos?: () => void` (só aparece se a prop vier);
   - lista dos pendentes como hoje (sem o rótulo "já está no perfil"/"fora do perfil"); sem pendentes e com `vazio`,
     "Nenhum relato fora do perfil." (mantenha o comportamento da prop `vazio` de hoje para o caso de lista vazia);
   - no fim, `<details>` (sem `open`) com `<summary>` "Relatos incorporados (N)" quando N > 0: cada um com a pergunta,
     o relato, a data, a vaga e só o botão "Apagar" (confirmação "Apagar este relato? O perfil não muda.");
   - remova o `<SecaoRevisaoPerfil origem="relatos" … />` deste componente (vai para a aba Conflitos) e o import, se
     ficar sem uso.
3. Não mude outros componentes.
