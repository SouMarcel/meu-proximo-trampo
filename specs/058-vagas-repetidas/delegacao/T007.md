# T007 — Seção "Vagas repetidas" na aba Limpeza

Spec: 058-vagas-repetidas
Tamanho: minor

## Contexto

Projeto: a página React de uma ferramenta local de busca de emprego. Você está na branch `frontend-react`. A mesma
vaga pode estar várias vezes no banco, vinda de portais diferentes, com a empresa escrita de outro jeito ("Alfaweb",
"Alfaweb Corp", "Seja Alfaweb"). O servidor acha esses grupos e, com o OK da pessoa, junta cada grupo na vaga
**principal**. Ao juntar, as outras saem das listas, e a principal ganha as etiquetas, a etapa mais adiantada, as
anotações e os currículos delas.

A aba **Limpeza** fica nos Filtros da busca, no componente `src/components/modals/LimpezaAba.tsx`. Leia-o: ele tem a
prévia de limpeza com caixas de seleção, a confirmação com `window.confirm` e as constantes de estilo (`SEC`, `H`,
`DICA`, `AVISO_AMBAR`, `BOTAO`). A nova seção segue o mesmo padrão e fica **no fim da aba**, depois do "Já
arquivadas".

Rotas do servidor (as duas só deste computador; 403 fora dele):

- **`GET /api/repetidas`** → `{ grupos: GrupoRepetido[] }`, com:

  ```ts
  interface ResumoRepetida { id: string; titulo: string; empresa: string; plataforma: string;
    etapa: string | null; triagem: string | null; aderencia: number | null; tem_descricao: boolean }
  interface GrupoRepetido { ids: string[]; principal: ResumoRepetida; outras: ResumoRepetida[];
    etapa_final: string | null }
  ```

  Em `ids`, o primeiro é o da principal.
- **`POST /api/repetidas/juntar`** com `{ grupos: string[][] }`, que é a lista dos `ids` de cada grupo escolhido,
  exatamente como vieram → `{ juntados: number, vagas: number, ignorados: string[][], backup: string | null }`. Um
  grupo que mudou desde a prévia vai para `ignorados`.

`src/services/api/limpeza.ts` tem o padrão de serviço (`pedir`). Os rótulos das etapas estão em
`src/utils/rotulos.ts` (`ETAPAS`: `{ valor, rotulo }[]`).

## O que fazer

1. **`src/types/api.ts`**: os tipos `ResumoRepetida` e `GrupoRepetido` acima, mais
   `RespostaJuntar { juntados: number; vagas: number; ignorados: string[][]; backup: string | null }`, com um
   comentário que cite a spec 058.

2. **`src/services/api/limpeza.ts`**:
   - `repetidas = () => pedir<{ grupos: GrupoRepetido[] }>("GET", "/api/repetidas")`;
   - `juntar = (grupos: string[][]) => pedir<RespostaJuntar>("POST", "/api/repetidas/juntar", { grupos })`.

3. **`LimpezaAba.tsx`**: no fim da aba, uma `section` "Vagas repetidas":
   - texto (`DICA`): "A mesma vaga anunciada em mais de um portal, ou com a empresa escrita de outro jeito. Juntar
     deixa uma vaga só (a principal) com as etiquetas de todos os portais, a etapa mais adiantada, as anotações e os
     currículos das outras; as outras saem das listas. Antes, a ferramenta guarda uma cópia do banco.";
   - botão "Procurar repetidas" (`BOTAO`), desligado sem `podeSalvar` ou enquanto carrega. Ele chama
     `limpezaApi.repetidas()`;
   - sem grupos: "Nenhuma vaga repetida.";
   - com grupos, cada grupo num cartão `rounded-xl border p-2`, com uma caixa de seleção, **marcada por padrão**. O
     cartão mostra:
     - **Fica:** `titulo · empresa · plataforma`, mais `· etapa` (rótulo de `ETAPAS`), quando houver, e `· nota N`,
       quando houver;
     - **Junta:** uma linha por vaga de `outras`, no mesmo formato;
     - quando `etapa_final` existe e é diferente de `principal.etapa`: "Etapa final: {rótulo}", em âmbar;
   - botão "Juntar N grupos" (N = grupos marcados), desligado com N = 0 ou sem `podeSalvar`:
     - confirma com `window.confirm("Juntar N grupos de vagas repetidas? As outras vagas de cada grupo saem das listas (fica uma cópia do banco de antes).")`;
     - chama `limpezaApi.juntar(gruposMarcados.map((g) => g.ids))`;
     - mostra em verde "{juntados} grupo(s) juntado(s), {vagas} vaga(s) a menos. Cópia de antes: {backup}.", mais
       " {n} grupo(s) mudaram desde a prévia e ficaram de fora." quando `ignorados.length > 0`;
     - depois, limpa a lista;
   - erros: `role="alert"` em rosa, com `mensagemDeErro`, como no resto da aba.
