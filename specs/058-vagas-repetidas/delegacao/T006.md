# T006 — Etiquetas de todos os portais e "Link do anúncio original" no detalhe

Spec: 058-vagas-repetidas
Tamanho: minor

## Contexto

Projeto: a página React de uma ferramenta local de busca de emprego. Você está na branch `frontend-react`. A mesma
vaga pode ser anunciada em vários portais (Gupy, JobGether, LinkedIn…). O servidor já guarda os outros portais em
`vaga.outras_plataformas: string[]`, mas a página só mostra o portal principal (`vaga.plataforma`).

A etiqueta do portal é desenhada com `getPlataformaStyle(plataforma)` (de `src/utils/formatters.ts`), que devolve
`{bg, text, border, accent}`:

- no cartão das Vagas: `src/components/TriageReport.tsx`, perto da linha 433;
- no cartão das Aplicações: `src/components/JobCard.tsx`, perto da linha 73;
- no detalhe: `src/components/modals/JobDetailModal.tsx`, perto da linha 204.

Rota nova do servidor, `PUT /api/vagas/<id>/link-original`, com o corpo `{ url: string }`:

- 200 `{ juntada: string | null, vaga: Vaga, verificando?: string[], verificando_agora?: string | null }`:
  - `juntada` não nulo: a vaga daquele link **já estava no dashboard**, e as duas foram juntadas na vaga `juntada`;
  - se `juntada !== vagaAtual.id`, a vaga atual saiu das listas;
  - `juntada` nulo: a vaga atual ganhou a descrição do link, o link de candidatura e a etiqueta, e entrou na fila de
    nota.
- 422 `{ erro }`: o link não pôde ser lido.
- 403: fora deste computador.

No `JobDetailModal`:

- o modal recebe `onAviso(mensagem, tipo?)` e `onClose()`, e usa `useFerramenta()` (`podeGravar`);
- a aba "descricao" (perto da linha 211) já tem a seção `ColarDescricao` (spec 057). Siga o estilo dela.

O padrão de serviço é `src/services/api/vagas.ts`: `pedir<T>(metodo, caminho, corpo?)` e `id(vagaId)`.

## O que fazer

1. **`src/services/api/vagas.ts`**:

   ```ts
   linkOriginal = (vagaId: string, url: string) =>
     pedir<{ juntada: string | null; vaga: Vaga; verificando?: string[]; verificando_agora?: string | null }>(
       "PUT", `/api/vagas/${id(vagaId)}/link-original`, { url })
   ```

2. **Componente `EtiquetasPortais`**, num arquivo novo `src/components/EtiquetasPortais.tsx`:
   - recebe `{ vaga: Vaga; tamanho?: "sm" | "md" }` e renderiza um `<span className="inline-flex flex-wrap gap-1">`
     com uma etiqueta por portal: primeiro `vaga.plataforma`, depois cada item de `vaga.outras_plataformas` que seja
     diferente dele e não se repita;
   - cada etiqueta usa as classes de hoje (`px-2 py-0.5 rounded-lg text-xs font-semibold border ${bg} ${text} ${border}`);
   - as etiquetas dos outros portais ganham `title={`Também anunciada em ${p}`}`.

3. **Use `EtiquetasPortais`** no lugar da etiqueta única nos três lugares (TriageReport, JobCard e JobDetailModal).
   Não mude mais nada no layout.

4. **`JobDetailModal`**, aba "descricao": logo abaixo da seção `ColarDescricao`, que deve aparecer também quando ela
   não aparece, a seção **"Link do anúncio original"**:
   - `<input type="url">` com o placeholder "Cole o link para onde o portal leva a candidatura (ex.: o da Gupy)";
   - botão "Ler o link", desligado sem texto, sem `podeGravar` ou enquanto lê;
   - ao clicar, chama `vagasApi.linkOriginal(vaga.id, url.trim())`:
     - `juntada && juntada !== vaga.id`: `onAviso("A vaga já estava no dashboard: as duas foram juntadas.")` e `onClose()`;
     - `juntada === vaga.id`: `onAviso("A vaga já estava no dashboard: as duas foram juntadas nesta.")`;
     - `juntada` nulo: `onAviso("Link lido: a vaga ganhou a descrição e entrou na fila de verificação.")`;
     - erro: `onAviso(mensagemDeErro(e, "Não deu para ler o link."), "erro")`;
   - texto de ajuda (`text-xs text-slate-500`): "Quando um portal só repassa a vaga (o JobGether, por exemplo), cole o
     link do anúncio de origem: a ferramenta lê a descrição por ele e junta com a vaga, se ela já estiver aqui.".
