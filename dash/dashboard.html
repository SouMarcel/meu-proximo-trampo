Adicionar vaga

Cole o link de uma vaga que você achou em outro lugar: o dashboard lê os dados, coloca a vaga no Relatório de Vagas e o Claude analisa a aderência, como nas vagas da busca.

Sem link ou prefere digitar?

Com a descrição, o Claude analisa a aderência ao seu perfil: sozinho, se o Claude Code estiver instalado; senão, peça "analisa as vagas que adicionei no dashboard".
