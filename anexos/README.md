# anexos

A pasta onde você deixa arquivos para o Claude usar. Por exemplo:

- o seu currículo (PDF ou Word) e o PDF do seu perfil do LinkedIn, para montar o
  `perfil.md`;
- o texto de uma vaga cujo link não abre (LinkedIn e Indeed costumam bloquear);
- um retorno de recrutador ou um relatório de ATS;
- qualquer outro material que ajude: certificados, anotações, um currículo que você
  goste de usar como modelo.

Depois é só citar o arquivo ou a pasta no Claude Code: "monta meu perfil com o
currículo que está em anexos".

Tudo aqui fica só no seu computador: o Git ignora esta pasta, menos este README.
